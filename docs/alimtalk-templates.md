# 카카오 알림톡 템플릿 (승인 신청용)

솔라피 콘솔 → 카카오 → 템플릿 관리에서 아래 두 개를 등록해 카카오 승인을 받는다.
승인 후 발급되는 **템플릿 ID** 와 채널의 **pfId** 를 Supabase Edge Function 시크릿에 넣는다
(`SOLAPI_PF_ID`, `SOLAPI_TPL_REMINDER`, `SOLAPI_TPL_NOTICE`). 그 전까지 앱은 아무것도 보내지 않는다.

변수는 `#{이름}` 형식. 버튼은 "웹링크" 유형, 링크는 `#{링크}` 변수(앱 주소).

---

## 1. 예약 리마인드 (`SOLAPI_TPL_REMINDER`)

- 템플릿 이름: 산사캠프 프로그램 시작 안내
- 카테고리: 예약/스케줄 안내 (정보성)
- 발송 시점: 예약한 프로그램 시작 10분 전 자동

```
[산사캠프] 프로그램 시작 안내

#{닉네임}님, 예약하신 프로그램이 곧 시작됩니다.

▶ 프로그램: #{프로그램}
▶ 시작 시간: #{시간}
▶ 장소: #{장소}

입장 시 QR 팔찌 또는 앱의 입장 QR을 보여주세요.
참여가 어려우면 앱에서 미리 취소해 주세요. (노쇼 2회 시 당일 예약 제한)
```

버튼: `내 예약 보기` → `#{링크}`

## 2. 운영 공지 (`SOLAPI_TPL_NOTICE`)

- 템플릿 이름: 산사캠프 운영 안내
- 카테고리: 행사/이용 안내 (정보성)
- 발송 시점: 관리자가 앱에서 알림을 발행할 때 수신 동의자 전원

```
[산사캠프] #{제목}

#{내용}

자세한 내용은 앱 알림 탭에서 확인하세요.
```

버튼: `앱에서 보기` → `#{링크}`

---

### 승인 시 참고

- 두 템플릿 모두 광고 문구 없이 정보성으로 작성했다. 할인·홍보 문구를 넣으면 반려된다.
- `#{내용}` 처럼 자유 입력 변수는 길이 제한(변수 포함 1,000자)만 지키면 된다.
- 수신 대상은 앱에서 "카카오 알림톡으로도 받기"를 켠 사용자 중 휴대폰 번호가 연결된 계정만이다.
- 알림톡 실패 시 문자 대체 발송은 기본 꺼짐. 켜려면 시크릿 `ALIMTALK_SMS_FALLBACK=true`.
